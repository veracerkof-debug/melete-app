# Melete

**Μελέτη** (греч. «упражнение, усердное занятие», 1 Тим 4:15) — рабочий стол музыканта: учёт занятий и набор
инструментов, которые открываются прямо в занятии. Без рекламы, подписок, аккаунтов и сбора данных — всё хранится
на устройстве. Ритм недельный, без давления ежедневными сериями. Мера успеха — время за инструментом, а не в телефоне.
Открытый код, GPL‑3.0.

*English — [README.en.md](README.en.md).*

## Что умеет

**Практика**
- Занятия: свободные, по песне и в инструменте. Инструменты открываются окнами прямо в занятии (весь экран,
  половины, четверти, полосы); время считается по признакам игры и не сбивается при погасшем экране.
- Неделя: расписание занятий как в календаре (несколько в день, перерывы, правка одного дня), цель недели,
  напоминания, честная статистика по дням, песням, жанрам и меткам. Помодоро и секундомер «сколько я играю».
- Камень, который скругляется от часов практики, как галька в реке; маскот Мелета или Мелетий (или без маскота).
- Учёба: учебник теории (академический и джазовый разделы, путь новичка), тренажёры слуха и ритма с уроками.

**Песни, календарь, команда**
- Библиотека песен: категории, жанры, метки, выученность, темп, текст с аккордами, табы, ноты и записи к песне.
- Календарь и сцена: репетиции, уроки, концерты; сет-лист с темпом, кликом, пэдом, минусовкой и автопрокруткой.
- Команда: песни, табы и сет-листы одним файлом `.melete` через «Поделиться» — без серверов.
- Церковный режим (выключен по умолчанию): Библия, планы чтения, модули MyBible, импорт песен из ProPresenter,
  EasyWorship, OpenLyrics, PowerPoint и Holyrics.

**Инструменты**
- Метроном (полиритм, тренер темпа, вспышка и вибрация), тюнер, пианино (рояль по записям и синтезатор), пэды
  с арпеджиатором, теория (круг, гаммы, аккорды, транспонирование).
- Глайдер — бесладовая клавиатура; терменвокс — игра руками перед камерой (камера обрабатывается только на устройстве).
- Медиатека: замедление без смены высоты, тональность, A–B, метки, видео; запись сама делится на дорожки (вокал,
  ударные, бас…), определяются тональность, темп, доли и аккорды; ноты из записи; конвертер форматов.
- Табы и ноты (Guitar Pro, MusicXML, PDF), текст с аккордами, партия «с игры».
- Диктофон с обработкой вживую и после записи; лупер; базовая студия для набросков; спектр и шумомер.
- Запись в любом инструменте: звук, видео или MIDI; MIDI-клавиатура по USB и Bluetooth.

**Данные и связь**
- Папка Melete: данные, записи, табы, PDF и тексты лежат по полочкам, медиатека и папка — зеркало друг друга;
  копии с подписью (кто и когда), на устройстве — копии каждый день и перед обновлением.
- Телефон и компьютер синхронизируются в своей сети Wi‑Fi (защищённое соединение, сопряжение по коду); тяжёлый
  разбор записей может считать компьютер.
- Языки: русский, oʻzbekcha (латиница), English. Оформление: классика и «Минимал», темы, палитры, свои цвета.

В веб-версии нет напоминаний, папки Melete, иконки на выбор, управления звуком из шторки и тяжёлых моделей
(дорожки, ноты, аккорды).

**Демонстрация** — [veracerkof-debug.github.io/melete-app/show](https://veracerkof-debug.github.io/melete-app/show/):
выдуманный музыкант с песнями, табами, записями, календарём и почти двумя годами занятий. Хранится отдельно от
настоящих данных; можно трогать что угодно.

Приложения обновляются сами из релиза своего канала.

## Разработка

```
npm install        # зависимости
npm run dev        # сервер разработки (с телефона по Wi-Fi: http://<IP компьютера>:5173)
npm test           # тесты логики (Vitest)
npm run e2e        # сквозные проверки в браузере (Playwright)
npm run build      # сборка в dist/
npm run models     # скачать модели (дорожки, ноты, разбор) по build/models.json
npx cap sync android
```

Документация для разработчика:
- `ARCHITECTURE.md` — замысел и устройство проекта: с него начинать;
- `docs/tech/` — главы: данные, ядро, модули, звук, музыка и разбор записей, связь, платформы, надёжность, тесты, соглашения;
- `MODULE_SPEC.md` — контракт модуля-инструмента;
- `DECISIONS.md` — решения автора; `ROADMAP.md` — план; `docs/README.md` — все документы.
