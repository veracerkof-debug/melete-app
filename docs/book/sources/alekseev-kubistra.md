# Опись: Р. Алексеев («Анатомия музыки») и таблица Kubistra

Три коротких материала. Прочитаны глазами, без OCR.

## 1. «Сборник упражнений по гармонии» (16 с.)

Страницы 8–10 и 15 — реклама курса. Не переносить.

### Письменные задания (часть 1)

1. **Впишите недостающие звуки.** Дан символ (D7, A♭maj7, Em7♭5, F°7, G+7, A7♭9, F♯m9, E♭maj9, F♯m7♭5, Am6, B9, D♭9, A♭9sus4, Fmaj9♯11, E7♭9, Cm(maj13)) и часть звуков; дописать остальные.
   → Тренировка: «дан аккорд и 2–3 звука на стане — дописать недостающие на клавиатуре».
2. **Переписать звуки аккорда по квартам** (кварта может быть увеличенной). C6/9, F13, Dm11, A9, E♭maj13, Am11♭5, Em13. Бас остаётся.
   → Схема «Аккорд в квартах»: аккорд терциями → те же звуки квартами над тем же басом, со звуком.
3. **Заполнить тремя звуками расстояние между басом и верхним звуком** по символу. Наибольший интервал между соседними голосами — б7 по фактическому расстоянию; без надстроек. Ряды: Am7 с верхом 1, ♭3, 5, ♭7, 9, 11, 13 (Am9, Am11, Am13); Cm7, B♭7 (B♭9, B♭9♯11, B♭13♯11), A♭maj7 (maj9, maj9♯11, maj13♯11), G°7 (G°9, G°11, G°13).
   → Упражнение «расположение под мелодию»: дан бас и верхний звук, набрать середину; проверка — звуки аккорда, промежуток ≤ б7.
4. **Подписать буквенные обозначения аккордов в фортепианной пьесе** (энгармонически переосмысляя ноты, с учётом мелодии). Ответы — B♭maj7, E♭m6/B♭, Am11♭5, D7(♭9♭5), A°, Gm9, Cm/G, G♭7, Am7♭5, D7(♭13♭9), C7, F13sus4, F13.
   → Чужую пьесу не переносить; механика — «назови аккорд по нотам» (в тренировке частично есть).
5. **Расположить аккорды по квинтам** (квинтаккорды): C6/9, Fm11, G13, Dm9♭5.
   → Схема «по квартам / по квинтам» — одна схема с переключателем.
6. **Найти основные тоны аккордов и подписать в басу** (возможны варианты — выбрать самые простые). Ответы: F9; Dm7 или F6; E♭maj9; G7; Em9; A7♭5 или E♭7; B♭7♯5.
   → Тренировка «найди корень»: показан голос без корня → выбрать бас; принимать все верные (аккорд без корня неоднозначен — это и есть урок).
7. **Гармонизовать мелодию только данными аккордами.** A: Cm7, Fm7, Gm7. B: E♭maj7, Cmaj7, G7sus. C: Gm7, G♯m7, E♭7♯11, D7♯9.
   → Схема: короткая своя мелодия по тактам + набор из 3–4 аккордов; человек выбирает аккорд на каждый такт; проверка — нота мелодии на сильной доле = звук аккорда или доступное напряжение; затем проигрыш.
8. **Подписать кластерные аккорды буквой.**
   → Тренировка «кластер → символ».

### Игра на фортепиано и сольфеджио (часть 2)

Мысль автора: игра гармонических упражнений на фортепиано — неотъемлемая часть учёбы для любого инструмента и вокалиста; виртуозность не нужна — достаточно знать ноты и строить аккорды.

1. **Дан один звук аккорда с его ступенью** (Amaj7 — C♯ = 3; Fm7 — C = 5; D♭7 — B = ♭7 …) — сыграть его и **пропеть остальные звуки** аккорда.
2. **Сыграть аккорд без одного звука и пропеть недостающий.**
3. **Играть цепочки аккордов и петь линию направляющих тонов** (две цепочки по 10 аккордов, линия дана).
4. **Играть аккорды и строить голосом нону (9)**: Am7, Gmaj7, Fm7, E♭m7, D7, G7, C7, F7, B♭maj7, G♭maj7, Dmaj7, Bmaj7.
5. **Петь одну ноту и найти как можно больше вариантов её гармонизации.** Пример на B: G6, Em7, E♭maj7, D7sus4, D♭7♯11, Cmaj7, B7alt, B♭7sus4, Am11, A♭maj7.
   → Схема «Одна нота — много аккордов»: выбрать ноту; схема перечисляет аккорды, где она звук аккорда или напряжение (с подписью ступени: «B — 3 у G6, 5 у Em7, ♯5 у E♭maj7…»); касание — аккорд звучит под выдержанной нотой. Проверка пением — тюнером (по желанию).

Упражнения 1–4 — «петь ступень над аккордом»: приложение играет аккорд, человек поёт; тюнер проверяет.

## 2. «Практическое руководство по игре ладов» (2 с.)

**10 необходимых ладов**, сгруппированных по звучанию:
- мажорные: ионийский, лидийский (♯IV), миксолидийский (♭VII);
- минорные: эолийский, дорийский (♮VI), фригийский (♭II); «остальные минорные» — локрийский (♭II, ♭V);
- доминантовые: миксолидийский, лидийский доминант (♯4), альтерированный (♭9 ♯9 ♯11 ♭13 — в оригинале подписан «лидийский доминант», это опечатка), уменьшённый «полутон–тон» (♭9 ♯9 ♯11).

Группировка «мажорные / минорные / доминантовые» и отметка одной-двух характерных ступеней — та же мысль, что у нас («лад = мажор или минор с одной изменённой ступенью»); новое — **группа доминантовых ладов**.

**Упражнения на лад** (на примере C миксолидийского, восьмыми):
1. Гамма лада на октаву **от каждой ступени по очереди, меняя направление**: I вверх, II вниз, III вверх, IV вниз … VII вниз, I вверх.
2. То же **в обратном порядке ступеней**: от I вниз, от ♭VII вверх, от VI вниз … к I.
3. **Лад по хроматизму:** C миксолидийский вверх, D♭ миксолидийский вниз, D вверх, E♭ вниз … — лад последовательно во всех 12 тональностях, направление чередуется.
→ Генератор с проигрышем и метрономом (лад × упражнение × тональность). Совпадает по духу с Левайном (L44 «гамма не от корня, цепочка ладов»); новое — «лад по хроматизму» и строгая форма упражнения.

## 3. Kubistra, «Jazz Scales Degree» (1 с.)

Гаммы записаны **как аккорд + напряжения** и сгруппированы по **виду аккорда**:

| Семья | Гамма | Ступени |
|---|---|---|
| Мажор | ионийский | 1 9 3 **s4** 5 13 7 |
| | лидийский | 1 9 3 ♯11 5 13 7 |
| Минор | дорийский | 1 9 ♭3 11 5 13 ♭7 |
| | эолийский | 1 9 ♭3 11 5 **s♭6** ♭7 |
| | фригийский | 1 **s♭2** ♭3 11 5 **s♭6** ♭7 |
| | гармонический минор | 1 9 ♭3 11 5 **s♭6** 7 |
| | мелодический минор | 1 9 ♭3 11 5 13 7 |
| Доминанта | миксолидийский | 1 9 3 **s4** 5 13 ♭7 |
| | лидийский ♭7 | 1 9 3 ♯11 5 13 ♭7 |
| | альтерированный | 1 ♭9/♯9 3 — ♭5 ♭13 ♭7 |
| | уменьшённый «полутон–тон» | 1 ♭9/♯9 3 ♯11 5 13 ♭7 |
| | целотоновый | 1 9 3 — ♭5 ♭13 ♭7 |
| Уменьшённый | «тон–полутон» | 1 9 ♭3 11 ♭5 ♭13 𝄫7/7 |
| | локрийский | 1 **s♭2** ♭3 11 ♭5 ♭13 ♭7 |
| | локрийский ♮9 | 1 9 ♭3 11 ♭5 ♭13 ♭7 |

«s» (серым) — неудобная нота («avoid»). Взгляд отличается от нашего: у нас гаммы идут от родительских гамм (мажор → его лады), здесь — **от аккорда**: какие гаммы годятся к семье и чем они отличаются одной-двумя ступенями. Совпадает по сути с Jazzology 13.7 («семьи аккорд — гамма»), но в виде одной наглядной таблицы ступеней-напряжений с пометкой неудобных нот. Это готовый вид для справочника и для схемы «Гамма к аккорду» (переключатель «ступени / напряжения»).
