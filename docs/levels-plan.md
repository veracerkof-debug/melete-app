# Предложение: четыре режима при регистрации (25.11.2026)

Статус: **предложение, ждёт слова автора** (правило 11); кода по нему нет.

## Что есть сейчас (по коду)
- Уровень выбирается на регистрации (`core/screens/onboard.js`), подсказка по часам опыта: до 150 ч — новичок, 150–1000 — средний, 1000–5000 — продвинутый, больше — профи (`profile.js`).
- Уровень задаёт: набор включённых инструментов (новичок — метроном, тюнер, ноты, медиатека, учебник; средний — ещё пианино, пэды, теорию, таймер, терменвокс; продвинутый и профи — все), цель недели (3 / 5 / 10 / 15 ч), режим тюнера «новичок» и «ноты в одной октаве» у глайдера, какие разделы учебника видны (новичку — «Первые шаги» и курс гитары, остальным — школа и джаз).
- Ничего не закрыто: всё включается в «Настройки → Функции». Закрывает только отдельный режим «Ученик» (код учителя).

## Предложение: принцип
Уровень — это **что показано по умолчанию и как с человеком разговаривают**, а не замок. Новичку — узко и за руку, профи — всё и без подсказок. Любой уровень можно поменять в профиле; остальное включается в «Функциях». «Ученик» (с кодом) — это новичок плюс замок.

| | **Новичок** (до 150 ч) | **Средний** (150–1000 ч) | **Продвинутый** (1000–5000 ч) | **Профи** (больше 5000 ч) |
|---|---|---|---|---|
| Инструменты | метроном, тюнер (с подсказкой струн), диктофон, ноты и табы, учебник; пианино, слух и ритм — только внутри уроков | + пианино, пэды, теория, таймер, глайдер, тренажёры слуха и ритма, лупер | все инструменты | все + пульт выступления, студия, ансамбль включены сразу |
| Главная | «Практика», один блок «Следующий урок», быстрый доступ 3 кнопки, неделя и камень; без календаря и сцены | + «Повторить» (песни), календарь, быстрый доступ 4 | + сцена, цели по песням, статистика по инструментам | + репетиции, учитель, синхронизация |
| Песни | короткая карточка: название, аккорды, темп | все поля, шкала выученности, цели по темпу | + список выступлений, разбор записи | + экспорт, пакеты для группы |
| Учебник | «Первые шаги» и курс по инструменту, шаг за шагом | + «школа» (теория музыкальной школы) | + джаз | + продвинутые главы |
| Настройки | короткий список; остальное под «Ещё» | основной список | полный | полный + связь, копии, учитель |
| Подсказки | инструкции включены, маскот говорит чаще | инструкции по запросу | без подсказок | без подсказок, рекомендуется «Минимал» |
| Цель недели | 3 ч | 5 ч | 10 ч | 15 ч |
| ИИ-чат | только по кнопке, без записи в данные | доступ «читать» | доступ «читать и писать» | то же + вложения |

## Новое по сравнению с сейчас
- Новичок: узкая главная («Следующий урок»), короткая карточка песни, короткие настройки.
- Средний: «свободный режим с базовым набором» — открывается чуть шире, но без студии и сложного.
- Мягкое предложение повысить уровень: после 150/1000/5000 часов **в приложении** (или после курса) — один раз, без давления.
