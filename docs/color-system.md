# Система цветов Melete (21.11.2026)

Слово автора: «цветов в приложении куча — неплохо, но нужна система, чтобы элементы, настройки, функции и кнопки имели близкие или те же цвета, а глаз легко находил связанное».
Принцип: **цвет — это смысл, а не украшение**. Один смысл — один цвет (или соседние оттенки); новый цвет без смысла не добавляется.

## 1. Три слоя

1. **Акцент (`--tint`, охра)** — только «главное действие и выбранное»: залитые кнопки, выбранный пункт, ползунки, выключатель «вкл» не в счёт. Никакой инструмент не «владеет» акцентом.
2. **Семьи инструментов** — по тому, что человек с инструментом делает. Родственные — один оттенок или соседние (оттенки — из палитры `settings.palette`, поэтому система
   работает и в «Яркой», «Пастельной», «Лунном свете» и «Своём цвете»). Задано в `src/core/palettes.js` (`TOOL_FAMILY`, `TOOL_HUE`); тест `tests/palettes.test.js`.
3. **Состояния (токены `tokens.css`)** — одинаковый смысл везде: `--ok` (верно, готово, включено — зелёный), `--red` (запись, стоп, удалить, ошибка — красный),
   `--gold` (строгие часы, внимание), `--l2` (второстепенное), `--tint` (акцент). Хекс-значения этих смыслов в CSS не пишутся — только токены.

## 2. Семьи инструментов

| Семья | Оттенок | Инструменты (в скобках — соседний оттенок) |
|---|---|---|
| Время и ритм | оранжевый | метроном, таймер/помодоро; страницы настроек «Неделя», «Уведомления», «Статистика» |
| Звук и высота | бирюзовый | тюнер, дрон; (спектр — голубой); настройка «Звук» |
| Игра руками | индиго | пианино, глайдер; (терменвокс — фиолетовый) |
| Учёба | зелёный | тренажёр (слух · ритм · вокал); (теория, учебник — мятный) |
| Запись | красный | диктофон, лупер; (студия — розовый) |
| Медиа | розовый | медиатека, сцена |
| Тексты и ноты | коричневый | ноты и табы, Библия |
| Служебное | графитовый | конвертер; страницы «Оформление», «Вкладки», «Модули и функции», «Данные», «Обо мне»; «Связь» и «Помощь» — синий |

Объединённые инструменты (`docs/tool-merge.md`) берут цвет главного отдела: Тренажёр — зелёный, Студия — красный/розовый (по представителю), Теория — мятный, Глайдер — индиго.
Внутри инструмента отделы и карточки — **один цвет семьи** (оттенки светлоты), а не радуга: например, карточки упражнений «Слуха» — все зелёные.

## 3. Правила применения

- Значок инструмента, плитка в «Инструментах», быстрый доступ, строка в настройках, шторка и список — **один и тот же цвет**.
- Красный — только «запись / стоп / удалить / ошибка». Зелёный — только «верно / готово / учёба». Не использовать их как украшение.
- Данные человека (метки, категории, события, цвета треков) — его собственные цвета, система их не трогает.
- Гармонические функции в теории (тоника, субдоминанта, доминанта) — свой смысловой код, остаётся.
- Новый инструмент: выбрать семью в `TOOL_FAMILY`/`TOOL_HUE` (иначе тест красный); новый цвет состояния — токеном в `tokens.css` во всех темах.
- Контраст: цветной текст — только `--tint-text`, `--ok`, `--red` (проходят AA на своём фоне в каждой теме); цвет семьи — для значков и фонов.
