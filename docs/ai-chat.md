# Чат с нейросетью (решения автора 23–24.11.2026; код ещё не написан)

Опциональная функция: приложение прекрасно работает без неё. Выключена по умолчанию, включается в настройках.
Исключение из правила 3 (сеть только по кнопке) записано в `DECISIONS.md`.

## Подключение
- Человек вставляет адрес API, ключ и название модели; выбирает формат: **OpenAI-совместимый** (OpenAI, OpenRouter и др.)
  или **Anthropic**. Только `https://`. Локальные модели не поддерживаем (у кого есть — переделает под себя).
- Запросы — через нативный HTTP (Android: как `holyrics.js`; Windows/Linux: команда Rust), CSP `index.html` не трогаем.
  В обычной веб-версии функции нет (скрыта, правило 13).
- Ключ — только на устройстве, вне `practice.v1`, не попадает в копии, синхронизацию, экспорт.

## Доступ к данным (настраивает человек, с предупреждениями)
По категориям (песни и репертуар, статистика, расписание, папки/медиатека, журнал ошибок): «нет» / «чтение» / «чтение и правка».
Модель получает только открытое. Без «правки» у неё нет инструментов записи.
- Правки идут функциями ядра, как ручные; **перед правкой — копия**; по умолчанию каждое изменение подтверждается карточкой
  «Применить / Отклонить»; полностью автоматический режим — отдельная галочка с предупреждением (риск prompt injection из
  чужих текстов). Применённая правка остаётся в ленте чата с «Отменить» — журнал живёт в чате.
- Песни и данные модель выдаёт в формате `docs/ai-format.md` (`.melete.json`, поле `ref` — обновление существующей).
- Контекст: базовый общий + данные по ситуации в пределах открытого доступа; перед отправкой — оценка размера и предпросмотр.

## Чат
- Отдельный экран на весь размер окна; вход — касание лица маскота на главной. Закрытие — смахнуть шторку вниз (строка в `docs/gestures.md`).
- Системная инструкция: что такое Melete, формат данных, язык, уровень доступа; отвечает как маскот (имя Мелета/Мелетий и
  характер — из настроек пользователя). Инструкция правится в настройках.
- История хранится на устройстве (последние сессии), «Очистить», вне копий и синхронизации.
- Работает вне звукового тракта (третий принцип): запись и воспроизведение чат не трогает.

## Что умеет (по порядку работ)
1. Чат + подключение по ссылке + создание песен и вставка аккордов в текст.
2. Порядок в репертуаре (дубли, жанры, тональности, папки) — предложением списком.
3. Анализ статистики и репертуара (чтение).
4. Диагностика: журнал ошибок как категория чтения; модель объясняет и подсказывает, не чинит код и не меняет настройки без подтверждения.
5. Партии (транспозиция, упрощение через `.mid`/MusicXML) — позже, после чтения кода студии.
«Найти песню»: у модели нет интернета, аккорды «по памяти модели» помечаются «проверьте»; тексты целиком не выдаём.
