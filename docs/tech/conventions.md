# Как писать код здесь

Соглашения, которые видны во всём коде. Если их держаться, новый код читается так же, как старый, а правила проекта
(`CLAUDE.md`) соблюдаются сами собой.

## Файл

- **Заголовочный комментарий обязателен**: что это, зачем, как связано с остальным (какие файлы, плагины, ключи
  хранения). Часто — со ссылкой на решение: «слово автора 11.11.2026», «DECISIONS 2026-10-28». Читатель должен понять
  файл, не открывая соседние.
- Комментарии и тексты журнала — **по-русски**, коротко, по делу: почему так, а не что делает очевидная строка.
  Имена в коде — по-английски, короткие (`st` — настройки, `rec` — запись файла, `a` — активное занятие, `p` — план).
- Строки длинные и плотные — так исторически; разбивайте, где это помогает читать. **Не ставьте `//` посреди строки
  кода** перед продолжением — остаток строки станет комментарием; внутри строки — только `/* */`.

## Логика и интерфейс раздельно

- Логика — в `core/` и `music/` **без DOM**: чистые функции или «создатели» `createX(зависимости) → объект`.
  Зависимости — аргументами (хранилище, база, часы `now`), не глобально: так логика проверяется тестами в Node.
- Экран — функция, которая отдаёт строку HTML; нажатия — делегированием по `data-`атрибутам; всё от человека —
  через `esc()` (`core.md`). Фреймворк не добавляется.
- Время — аргументом `now = Date.now()` в функциях логики; неделя с понедельника, местное время (`core/time.js`).

## Данные

- Новое поле — **необязательное**, с умолчанием при чтении; старые поля не удаляются, пока их читает старый код или
  старые копии. Миграции — маленькие идемпотентные функции при запуске (`data.md`).
- Удаление — пометкой `deleted`, правка — с `updatedAt`: иначе не сработают копии и синхронизация.
- Поля печати записи о занятии не менять (`data.md`).
- Новый ключ localStorage — с префиксом `melete.`; общее (переезжает с человеком) — в `settings`, своё для
  устройства — в `device` (`practice.v1.tools`).
- Файлы — в IndexedDB через `core/files.js`; результат обработки — новым файлом рядом с исходником.

## Звук

Правила — `audio.md`: один контекст; узлы не переподключаются, правки — параметрами и плавно; таймеры — `after` /
`every` из `audio/clock.js`, не `setTimeout`; отпущенный голос отключает все узлы; живой звук и файл — один код.

## Интерфейс

- **Строки** — только `t('key')` (у модулей `ctx.t`) в трёх языках: ru, uz (латиница), en. Тексты нейтральные,
  без «ты» и «вы»; лаконично, профессионально, без шуток там, где человек работает.
- **Доступность**: `aria-label` у кнопок без текста, цели касания ≥ 40 px, контраст, ролевые кнопки доступны с
  клавиатуры.
- **Размеры**: модуль работает в `full`, `half`, `quarter`, `strip`; стили — от размера окна (container queries).
- **Цвета** — только переменными темы (`styles/tokens.css`); проверка во всех темах и в «Минимале».
- **Жесты** — общими средствами (`ui/gestures.js`, `ui/hold.js`), новый — строкой в `docs/gestures.md`; кнопка
  остаётся для точной правки.
- Рабочая поверхность — на всё окно; надписи, не помогающие играть, — убираются.

## Сеть, зависимости, приватность

- Сеть — только по нажатию кнопки (исключение — проверка обновления). Никакой аналитики, рекламы и трекеров;
  микрофон и камера — только локальная обработка.
- Новая зависимость: лицензия совместима с GPL‑3.0; строка в `LICENSES.md` и на экране «Лицензии»; проверка кода
  пакета на скрытые сетевые обращения (`grep https://`). Всё — внутрь проекта, без CDN.
- В журнал и диагностику — ничего личного: ни названий, ни текстов, ни имени, ни звука.

## Новое — обратимо

- Новая функция — выключаемая; варианты (звуки, виды, алгоритмы) — строкой в `core/variants.js`: в dev все с
  переключателем, в pre — выбранный автором.
- Заметное для людей — запись в `core/whatsnew.js`.
- Значимое решение — запись в `DECISIONS.md`; этап — галочка в `ROADMAP.md`; новый файл с заметной ролью — строка в
  нужной главе `docs/tech/`.

## Чек-лист перед отправкой

1. `git merge origin/main` в свою ветку.
2. `npm test` — зелёное; новые тесты на новую логику.
3. Сквозные проверки по затронутым экранам.
4. `npx vite build` — собирается.
5. Перечитать свой дифф глазами проверяющего: что сломается на слабом телефоне, без микрофона, при обрыве?
6. Коммит — по-русски, что и зачем.
