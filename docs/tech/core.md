# Ядро и экраны

Как приложение собирается при запуске, как рисует экраны и как ведёт занятие. Данные — в `data.md`,
модули-инструменты — в `modules.md`.

## Запуск: объект `app`

`src/main.js` подключает стили, ставит режим компьютера (`ui/desk.js`), загружает язык и вызывает
`core/index.js: boot(root)`. `boot` выполняет шаги строго по порядку — порядок важен:

1. **Журнал и диагностика** (`log.js`, `diag.js`) — первыми, чтобы ошибки запуска тоже попали в журнал.
2. **Возврат после проверок** (`cleanup.js`) — до чтения данных.
3. **Хранилище** (`store.js`; проекты студии — своя база `projstore.js`, читается сразу после запуска) и **шаги
   формата данных** (`migrate.js`).
4. **Язык, палитра, тема** (`i18n`, `palettes.js`, `applyTheme`).
5. **Настройки устройства** (`device.js`) и их приведение к нынешнему виду.
6. **Звук** (`audio/index.js: createAudio`). Объекты создаются сразу, а `AudioContext` — на первом жесте
   (браузеры запрещают звук без жеста).
7. **Файлы** (`files.js`), **запись** (`recorder.js`; через 2,5 с — восстановление оборванной записи),
   обработки (`jobs.js`, `autostems.js`), пакеты моделей, MIDI.
8. **Сессия, активность, часы, напоминания**, затем папка, синхронизация, гостевой сервер, копии, обновление,
   «Что нового».

Результат — один объект **`app`** (`store`, `device`, `audio`, `files`, `rec`, `session`, `folder`, `syncCli`,
`updater`…). Экраны получают `app` целиком; модули — только `ctx` (`modules.md`). Тесты собирают `app` по частям:
почти каждая часть — `createX(зависимости)` без глобального состояния.

## Как рисуются экраны

Фреймворка нет — это осознанное решение (прототип написан так же, кода меньше, всё прозрачно):

- экран — функция, которая возвращает **строку HTML**; её вставляют в `innerHTML` контейнера;
- нажатия ловит **один обработчик на контейнер** (делегирование), действие определяет `data-`атрибут
  (`data-act="export"`, `data-snap="…"`);
- после изменения данных экран просто рисуется заново (`render()`); подписка — `store.subscribe`;
- всё, что приходит от человека (названия песен, тексты), проходит через `esc()` из `ui/index.js`.

Общие элементы (`ui/index.js`): шторка `sheet(render, init)` (снизу, закрывается жестом вниз, стек шторок),
`toast`, `confirm`, переключатель `sw`, сегменты `seg`, `snav` — заголовок шторки. Клавиатура пианино —
`ui/keyboard.js`, эквалайзер — `ui/eq.js`, панель эффектов — `ui/fxpanel.js`, удержание и перетаскивание —
`ui/hold.js`, жесты — `ui/gestures.js`.

Экраны ядра — `src/core/screens/`:

| Файл | Экран |
|---|---|
| `shell.js` | каркас: нижние вкладки (состав и порядок — в настройках), переходы, общие действия |
| `home.js` | главная: кольцо недели, план дня, учёба, слово маскота |
| `songs.js` | библиотека песен и карточка песни |
| `calendar.js`, `stage.js` | календарь; сет-лист и сцена (автопрокрутка, педаль) |
| `tools.js`, `arrange.js` | «Инструменты»; правка вкладок и порядка удержанием |
| `session.js`, `mixer.js`, `fx.js` | занятие с окнами; микшер сбоку; эффекты шины |
| `panel.js` | панель профиля: профиль, неделя (`plan.js` — расписание), статистика, настройки, данные |
| `onboard.js` | регистрация (одна страница) |
| `diag.js`, `selfcheck.js`, `report.js` | диагностика, самопроверка, отчёт о проблеме |
| `share.js`, `backupsheet.js`, `update.js`, `whatsnew.js` | обмен, копии, обновление, «Что нового» |

«Назад» на Android (`core/back.js`) закрывает верхнее: диалог → шторка → панель → окно → сессия (сворачивается) →
песня → первая вкладка → приложение сворачивается.

## Занятие (сессия)

Логика — `core/session.js` (чистые функции над объектом «активное занятие»), учёт признаков игры — `core/activity.js`,
экран — `screens/session.js`, раскладка окон — `core/workspace.js`.

- **Начало**: `createActive({ type, songId, tool, mode })`. Виды: свободное, по песне, в инструменте.
- **Время** считается отрезками: паузы и «вдали» (экран погас, а в строгом режиме время идти не должно) хранятся
  как `[от, до]`. Поэтому завершение «задним числом» (по последнему действию) вычитает ровно то, что нужно.
- **Признаки игры**: касания и клавиши (`touch`), звук приложения (`noteHeard`), по желанию — громкость микрофона
  (звук не записывается). Долго ничего — занятие спрашивает «ещё играете?» и при молчании завершается по последнему
  действию (`idleAction`).
- **Режим учёта**: обычный (при погашенном экране время идёт, пока что-то звучит) и строгий (только экран).
- **Конец**: `summarize` → `buildRecord` → `commitSession` (печать, запись, событие для напоминаний и маскота).
- **Инструмент вне занятия** тоже учитывается (`recordToolTime`), но время, уже засчитанное занятием или
  секундомером, второй раз не идёт (`stopwatch.js` вычитает пересечение).

**Раскладка окон** (`workspace.js`): `F` — весь экран, иначе две буквы — верх и низ: `H` половина, `Q` две
четверти, `S` две полосы. Отсюда четыре размера модуля: `full`, `half`, `quarter`, `strip`.

## Неделя, статистика, расписание, напоминания

- `stats.js` — чистые функции `(sessions, songs, settings, now) → данные экрана`; неделя с понедельника, местное время
  (`time.js`). «Ударный режим» — по **неделям**, а не дням (принцип: без давления).
- `schedule.js` — расписание как в Google Календаре: блоки от–до по дням недели, несколько в день, перерывы по датам,
  правка «только этот день»; экран — `screens/plan.js` на странице «Неделя».
- `reminders.js` — уведомления телефона на неделю вперёд из расписания; пересчитываются при запуске, смене настроек
  и после занятия. Тексты — `remindtexts.js` по характеру маскота; тихие часы.
- `calendar.js` — события (репетиции, уроки, концерты), повторы, раскладка, выгрузка `.ics`.
- `mastery.js` — самоцвет по часам практики в приложении (часы «до приложения» не считаются); `tama.js` — маскот
  на занятии.

## Языки

`src/i18n/`: `ru.json` (основной и запасной), `uz.json` (латиница), `en.json`; `el.json` — названия для вида «Минимал»
(греческий). Строки ядра — `t('key')`, множественное число — `tn('key', n)` (формы — массивом). У модуля — свой
словарь (`modules/<id>/i18n/*.json`), ему отдаётся `ctx.t`. Узбекский и английский грузятся отдельными файлами по выбору.

Правила: каждая строка интерфейса — ключом в трёх языках; тексты нейтральные, без «ты» и «вы»; в en и uz нет
кириллицы. Совпадение ключей проверяет `tests/i18nkeys.test.js`.

## Оформление

- `styles/tokens.css` — все цвета CSS-переменными (`--bg` фон, `--ink` текст, `--l2`/`--l3` приглушённое, `--fill`, `--cell`, `--sep`, `--tint`…); темы: светлая,
  тёмная, «Бумага», OLED. Цвета в коде стилей — только через переменные.
- `core/palettes.js` — у каждого инструмента свой оттенок; палитра задаёт, как оттенки выглядят.
- `styles/mono.css` — вид «Минимал» (`data-style="mono"`), `styles/desk.css` + `ui/desk.js` — режим компьютера
  (`html.desk`: навигация слева, колонки), `styles/motion.css` — движение.
- Порядок подключения стилей важен (`main.js`): общие → сессия → модули → движение → «Минимал».
- Размеры окна модуля — container queries, а не размер экрана.

## Жесты

`ui/gestures.js` — смахивание между экранами и щипок; `ui/hold.js` — удержание (меню) и перетаскивание (`dragSort`).
Жесты не работают у края экрана (там «Назад» Android), в полях ввода и на горизонтальных полосах прокрутки (кроме
их края). Карта всех жестов — `docs/gestures.md`; новый жест — строка туда.
