# Техническая документация

Как устроена Melete изнутри. Начните с карты `ARCHITECTURE.md` в корне — там замысел и общая картина;
здесь — главы по темам. В каждой главе: зачем так сделано, как устроено, где в коде, на чём легко споткнуться.

| Глава | О чём |
|---|---|
| [data.md](data.md) | данные и хранение: `practice.v1`, IndexedDB, печать занятий, слияние, копии, папка Melete, миграции |
| [core.md](core.md) | ядро и экраны: запуск и объект `app`, как рисуются экраны, занятие, неделя и расписание, языки, оформление, жесты |
| [modules.md](modules.md) | модули-инструменты: устройство, `ctx`, список встроенных, как сделать свой |
| [audio.md](audio.md) | звук: пять правил, граф и шины, источники, плееры, запись, нагрузка |
| [music.md](music.md) | музыкальная логика (`src/music`), разбор записей моделями, очереди обработок, модели, учебник |
| [connect.md](connect.md) | связь и обмен: правило сети, файл `.melete`, синхронизация, гости, ансамбль, LocalSend |
| [platforms.md](platforms.md) | веб, Android (плагины), Windows и Linux (Rust), каналы dev и pre, выпуск, модели и пакеты |
| [reliability.md](reliability.md) | надёжность: защиты данных и звука, журнал, диагностика, отчёт, известные долги |
| [testing.md](testing.md) | тесты логики и сквозные проверки, CI, правила |
| [conventions.md](conventions.md) | как писать код здесь: файл, логика и интерфейс, данные, звук, строки, чек-лист |

Связанные документы: `MODULE_SPEC.md` (контракт модуля), `docs/gestures.md` (жесты), `docs/share-format.md`
(файл `.melete`), `docs/studio-parity.md` (студия), `docs/guest-web.md` (гости), `docs/launcher.md` (Ἐλάχιστον),
`DECISIONS.md` (почему так).

Глава устарела — это ошибка, как и ошибка в коде: правьте её в той же работе, где меняете код.
