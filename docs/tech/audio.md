# Звук

Звуковой движок — `src/audio/`, на Web Audio API. Это самая чувствительная часть приложения: метроном,
пэды, пианино и плеер звучат одновременно, настройки меняются на ходу, а сбой звука на сцене стоит
музыканту денег. Отсюда несколько жёстких правил — их стоит прочитать до любой правки звука.

## Пять правил звука

1. **Один `AudioContext` на всё приложение** (`audio/context.js: getContext`). Создаётся на первом жесте человека;
   буфер выбирается по выходу (Bluetooth — больше, иначе треск) и по режиму «Задержка: низкая / средняя / надёжная».
2. **Узлы создаются один раз и не переподключаются.** Правка звука — только параметрами (`gain`, `frequency`…)
   и плавно (`setTargetAtTime`), без `disconnect/connect` на ходу: переподключение под нагрузкой даёт щелчки
   и обрывы. Тяжёлые узлы эффектов создаются, только когда эффект включён.
3. **Таймеры звука — из звукового потока.** `audio/clock.js: after / every / cancel` тикают из AudioWorklet
   (`wl/tick.worklet.js`, ≈ 25 мс) и не засыпают при погашенном экране, в отличие от `setTimeout`. Все планировщики
   (метроном, секвенсор, лупер, арпеджиатор) и отложенные отключения голосов — только через них.
4. **Отпущенный голос освобождается целиком.** После затухания голос отключает **все** свои узлы, включая посылы
   в реверберацию, — иначе за вечер копятся сотни мёртвых цепочек. Проверяет `tests/voiceleak.test.js`
   (поддельный AudioContext считает связи). Остановка параметра в будущем — `param.js: holdAt`, без щелчка.
5. **Вживую и в файле — одно и то же.** Сведение студии и обработка диктофона считаются в `OfflineAudioContext`
   тем же кодом и теми же узлами, что звучат вживую (`render.js`, `voicefx.js`, `vocal.js`).

## Граф

```
источник (голос пианино, клик, пэд, плеер…)
   └► шина инструмента (mixer.js: громкость, выкл) ─► эффекты шины (fx.js) ─┬► компрессор ─► выход
                                                                              └► посыл в пространство (spaces.js)
                                                                                     └► компрессор ─► выход
```

- **Шины** (`mixer.js: BUSES`): `metro`, `piano`, `glider`, `drone`, `media`, `looper`, `notes`, `theory`, `vocal` (аккомпанемент распевок). Состояние —
  `device.mix` (громкость 0…1,5, выключение, режим). Посыл в реверберацию — **после фейдера** (`wet(bus, space)`),
  поэтому ползунок шины глушит и хвост.
- **Эффекты** (`fx.js`) — одна цепочка для шин, слоёв лупера, дорожек студии и диктофона: эквалайзер (простой и
  продвинутый), сжатие, драйв, тремоло, задержка, хор, пространство. Кривые — чистые функции.
- **Пространства** (`spaces.js`) — четыре зала, два движка: свёртка (`ConvolverNode`, точнее и дороже) и лёгкий
  FDN в AudioWorklet (`wl/reverb.worklet.js`; на телефоне по умолчанию).
- Сборка всего — `audio/index.js: createAudio({ device, metroCfg, … })`; модули получают его как `ctx.audio`.

## Источники

| Файл | Что |
|---|---|
| `synth.js` | пианино и клавиши: пресеты со своими ручками, второй слой, до 22 голосов |
| `grand.js` | рояль по записям Salamander: полный (16 слоёв силы, пакет моделей) или облегчённый (веб) |
| `gm.js`, `sf2.js` | звуки General MIDI из банка SONiVOX (SoundFont) — для студии и нот |
| `drone.js`, `padvoice.js`, `arp.js` | пэды и дрон; голос-пэд для терменвокса; арпеджиатор пэдов |
| `airsound.js`, `wl/airvoice.worklet.js` | «воздушные» тембры; вариант движка — один узел AudioWorklet на ноту |
| `metronome.js` | планировщик `step` (без звука, тестируется) + звук; полиритм, группы долей |
| `drums.js` | ударные студии синтезом, без сэмплов |
| `sequencer.js` | проигрыватель проекта студии; правки клипов на ходу без перезапуска |
| `looper.js` | петля из слоёв: умножение, замена, отмена, такты, часы петли |

## Плееры медиатеки

- `stretchplayer.js` — основной: Signalsmith Stretch (WebAssembly в AudioWorklet, копия с правками —
  `vendor/signalsmith-stretch.mjs`, ищите «Melete»). Запись целиком внутри узла; скорость без смены высоты и сдвиг
  высоты — одним алгоритмом; дорожки записи с громкостью каждой смешиваются внутри узла — смена громкости мгновенна,
  звук не рвётся.
- `bufferplayer.js` — запасной на обычных узлах: включается сам, если AudioWorklet молчит (самопроверка или сторож
  тишины). Дорожки и громкость есть, тональности нет.
- `pitchshift.js` — сдвиг высоты для видео (звук элемента `<video>` через узел сдвига).

## Запись

- `voiceengine.js` — один движок записи для диктофона и записи в инструментах: входы и выходы (USB, Bluetooth,
  гарнитура), Android — плагин `Voice` (файл пишется на диск, заголовок WAV раз в секунду), браузер и компьютер —
  захват `wl/rec.worklet.js` с кусками в IndexedDB `melete-voice`.
- `core/recorder.js` — запись в инструментах (звук приложения + микрофон, видео модуля, MIDI); куски MediaRecorder —
  сразу на диск (`core/recspool.js`), оборванная сбоем запись восстанавливается при запуске.
- `vocal.js`, `livefx.js`, `voicefx.js`, `voicepresets.js` — режимы и обработка диктофона: срез → экспандер →
  де-эссер → тембр → компрессор → лимитер (`wl/vocal.worklet.js`), вживую и в файле одинаково; громкость по BS.1770.
- `capture.js`, `span.js` — захват звука по часам контекста (дорожка студии, сведение, отрезок шины).

**Исходник пишется как есть.** Обработка — отдельным файлом рядом; потерять запись из-за обработки нельзя.

## Нагрузка и слабые телефоны

- `load.js` — измеритель нагрузки звукового потока (`renderCapacity` браузера или свой зонд `loadprobe.js`).
  Показания — в микшере и настройках; перегрузка — в журнал и диагностику.
- `perf.js` — режим ресурсов: «полный» или «экономный» (меньше голосов, пэды без унисона, одна реверберация). Выше
  90 % нагрузки — **ужатие** (`squeeze`): новым нотам меньше голосов и унисона; нагрузка спала — обратно.

## Слух и анализ

- `pitch.js` — высота тона: YIN + уточнение по фазе (тюнер, пение в учебнике); `mic.js` — микрофон;
  `notein.js` — ноты с микрофона; `claps.js` — хлопки (тренажёр ритма).
- Разделение на дорожки, ноты из записи, тональность, доли и аккорды моделями — `music.md`.

## Чек-лист правки звука

- Новый узел в постоянной цепочке — создаётся один раз; управление — параметрами.
- Новый голос — `release()` отключает всё после затухания через `after()`; тест в `voiceleak.test.js`.
- Новый планировщик — на `clock.js`, с упреждением; проверка при погашенном экране.
- Проверка под нагрузкой: все инструменты сразу, смена настроек на ходу, слабый телефон («экономный» режим),
  Bluetooth на выходе, нет микрофона.
