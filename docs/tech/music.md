# Музыка и разбор записей

Две части: **`src/music/`** — музыкальная логика чистыми функциями, и **разбор записей моделями** — дорожки,
ноты, тональность, доли и аккорды из звука.

## `src/music/` — чистые функции

Без DOM, без звука, без глобального состояния; всё проверено тестами (`tests/music.test.js` и др.).
Часть функций сверена с прототипом.

| Файл | Что |
|---|---|
| `notes.js`, `theory.js` | ноты и правописание (диезы и бемоли по тональности), тональности, гаммы, аккорды, интервалы |
| `transpose.js`, `degrees.js`, `keycalc.js`, `identify.js` | транспонирование; аккорды ступенями относительно тональности; калькулятор тональности; определитель аккорда и гаммы по нотам |
| `tuning.js` | строи струнных |
| `lyrics.js` | текст с аккордами (`[Am]слово`), разбор и вывод |
| `guitarchords.js`, `fingering.js`, `fretboard.js`, `tabfinger.js` | схемы аккордов, аккорд по пальцам, гриф по кадру камеры, аппликатура табов |
| `midi.js` | события игры, MPE для скольжения, запись и чтение `.mid` |
| `musicxml.js`, `asciitab.js`, `livescore.js` | ноты проекта в MusicXML, текстовые табы → alphaTex, партия «с игры» |
| `quantize.js` | ноты со слуха → ритм по сетке долей записи, паузы, инструмент по характеру нот |
| `project.js` | проект студии: дорожки, клипы на таймлайне, ноты, аккорды, шаги ударных, записи; старые форматы переезжают сами |
| `daw.js` | файлы студий (Ableton `.als`, Reaper `.rpp`, FL Studio `.flp`) и `.mid` → песня для студии |
| `analyze.js`, `cqt.js` | темп и тональность по записи; лог-CQT по формулам librosa |
| `course.js`, `ear.js`, `rhythm.js` | уроки тренажёров (путь, сдача, повторение); упражнения слуха; ритмы по уровню и размеру |
| `melodies.js`, `folk.js` | мелодии по подсказке (общественное достояние); народные и микротоновые лады для глайдера и терменвокса |
| `mt3.js` | разбор выхода модели YourMT3+ в партии |

## Разбор записей: что и где

Все обработки — **на устройстве**, без сети. Результат — новые файлы рядом с записью или поля самой записи
(`data.md`); исходник не трогается.

| Задача | Движок | Где работает |
|---|---|---|
| Дорожки (вокал, ударные, бас, прочее; 2/4/6) | HTDemucs (ONNX) — `audio/stems.js`, `audio/demucs.js` | Windows (Rust, `src-tauri/src/demucs.rs`), Android (`Demucs.java`), браузер в dev (ONNX Runtime Web) |
| Улучшенный вокал | Mel-Band RoFormer + HTDemucs по инструменталу | Windows (`roformer.rs`), Melete DEV на Android (пакет) |
| Вокал/инструментал на телефоне | MDX-Net — `audio/mdx.js`, `Mdx.java` | Android |
| Ноты из записи | Basic Pitch (TensorFlow.js) — `audio/transcribe.js`; YourMT3+ — `audio/ymt.js` + `notes.rs` | везде / Windows |
| Тональность, доли, сильные доли, темп, аккорды | S-KEY, Beat This!, ChordMini — `audio/mir.js` (поток `mir.worker.js`, `mirpost.js`) | Android и Windows; в вебе — своя хрома (`core/songanalyze.js`) |
| Текст песни | whisper.cpp — `audio/lyrics.js` + `lyrics.rs` | только Windows |
| Шумоподавление | DeepFilterNet3 — `audio/denoise.js` + `denoise.rs` | только Windows |

Принцип «телефон лёгкий, тяжёлое — компьютер» (DECISIONS): ноты и аккорды по умолчанию считает компьютер, а телефон
получает результат синхронизацией (настройка «Считать на компьютере», `connect.md`).

## Очереди обработок

- `core/jobs.js` — **одна обработка за раз**, с ходом и отменой; результаты ложатся в медиатеку: дорожки — WAV с
  `stem: { src, part, mode, db }` (пустые не сохраняются), ноты — `.mid` с `trans: { src }`.
- `core/autostems.js` — фоновая очередь: каждая новая запись сама делится на дорожки (настройка: выкл / 2 / 4 / 6)
  и получает тональность и темп (`rec.ana`). Работает **только в тишине** — ничего не звучит, нет занятия и записи;
  зазвучало — прерывается и повторится позже. Порядок — от недавно слушанных; «Когда считать» — всегда или на зарядке.

Результат разбора `rec.ana`:
`{ pc, minor, cents, bpm, bpb, beats, downbeats, chords: [{ t, d, c }], v: 2 }` — плеер медиатеки рисует по нему
полосу аккордов, такты на волне, притягивает A–B к долям.

## Модели и пакеты

Модели в репозиторий не кладутся (они большие и чужие): опись — `build/models.json` (адрес, sha256, размер, платформа),
скачивание с проверкой — `npm run models` → `public/models/` (в `.gitignore`). Встраиваются в APK и Windows;
в веб-сборке их нет (`stemsSupported()` → нет).

Часть моделей на Android не встраивается, а скачивается по кнопке **пакетом** (`build/packs.json`, релиз `packs`,
`core/packs.js`, `PacksPlugin.java` — каждый файл сверяется по sha256). Модели только для Windows
(`platform: windows`) кладутся в ресурсы установщика (`src-tauri/models/`). Подробнее — `platforms.md`.

## Учебник

`src/modules/book/` — книга по теории на трёх языках: главы (`PARTS`), уроки (`lessons.js`), произведения
(`pieces.js`), схемы-«лаборатории» (`labs*.js`, движок `engine.js`, ноты шрифтом Bravura — `score.js`).
Тексты — `book/lang/<ru|uz|en>/`; в тексте `{{lab:id}}` — схема, `[[термин|слово]]` — ссылка на термин.
План и источники — `docs/book/`. Правило: своими словами, без чужих нот и мелодий (кроме общественного достояния).
