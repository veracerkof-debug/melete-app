# Связь и обмен

Melete работает без серверов и аккаунтов. Данные переходят между людьми и устройствами пятью путями; каждый
включается только по воле человека.

| Путь | Кому | Как | Модуль |
|---|---|---|---|
| Резервная копия | себе | файл JSON в папку Melete или через «Поделиться» | `core/backup.js` (`data.md`) |
| Папка Melete | себе, другим программам | папка на устройстве, зеркало медиатеки | `core/folder.js` (`data.md`) |
| Файл `.melete` | команде | песни, табы, сет-лист одним файлом через мессенджер | `core/share.js` |
| Синхронизация | своим устройствам | телефон ↔ компьютер в одной сети Wi‑Fi | `core/sync.js` |
| Гости, ансамбль, LocalSend | людям рядом | компьютер раздаёт в своей сети | `core/guest.js`, `ensemble.js`, `localsend.js` |

## Правило сети

Сеть — только по нажатию кнопки: поиск песни в MusicBrainz (`songinfo.js`), проверка часов (`clock.js`),
песни из Holyrics в своей сети (`holyrics.js`). Единственное исключение — проверка обновления раз в сутки
(`update.js`, режим «автоматически»). Политика страницы (`index.html`, `connect-src`) пропускает только свои
файлы, MusicBrainz, api.github.com и внутренний канал Tauri (`ipc:` — это не сеть, а связь окна с программой).
Аналитики, рекламы и трекеров нет; новая зависимость проверяется на скрытые обращения (`grep https://`).

## Файл `.melete`

`core/share.js`, формат — `docs/share-format.md`. Песни (название, исполнитель, тональность, темп, текст с аккордами),
их табы и ноты (по желанию — записи) и сет-лист. Личное **не отправляется**: выученность, текущий темп, метки,
время занятий. Принимается кнопкой «Принять файл» или открытием файла в Melete.

## Синхронизация телефона и компьютера

**Роли.** Компьютер (Windows/Linux) — сервер: посредник на Rust `src-tauri/src/sync.rs` принимает HTTPS на порту
53319 (Melete DEV — 53329) и передаёт запрос окну; всё решает JS-обработчик `sync.js: handleRequest`. Телефон —
клиент. В Melete DEV телефон тоже принимает подключения (`MeshServer.java`, плагин `Mesh`, тот же обработчик) —
связь всех со всеми.

**Сопряжение** — один раз. На компьютере включается «Связь с телефоном»: виден адрес и код из 6 цифр. Телефон
отправляет код (`/melete/v1/pair`), компьютер выдаёт ключ. Соединение — только TLS: у компьютера свой сертификат,
телефон **закрепляет его отпечаток** при сопряжении (`SyncHttpPlugin.java`) и дальше не отправит ключ никому другому.
Ключи сопряжения хранятся в `melete.sync` и в резервную копию не попадают.

**Что переносится.** Части копии `songs`, `profile`, `reading`, `calendar` — слиянием по `id` и `updatedAt`
(`data.md`). Файлы песен и медиатеки — кусками по 2 МБ (`/get`, `/put`), дорожки одной записи не задваиваются
(ключ «запись + часть + режим + версия»). Сведения, посчитанные позже (`ana`, `lyr`, привязки к песням), сливаются,
даже если файл уже есть на обоих (`/meta`, `/setmeta`). Удаления переносятся трёхсторонним сравнением: телефон помнит,
какие файлы были на обоих после прошлой синхронизации (`/delete`). Настройки и оформление у каждого устройства свои.

**«Считать на компьютере»** (`settings.pcWork`). Телефон не делит свежие записи сам, а оставляет их компьютеру;
компьютер берёт записи телефона в свою фоновую очередь (в режиме, который просил телефон: `rec.want`), результат
приходит при следующей синхронизации. Фоновая синхронизация (`settings.syncAuto`) — только в тишине. Компьютера нет
дольше суток — телефон считает сам.

**Пульт** (`netctl.js`, DEV): сопряжённое устройство управляет звуком, метрономом, пэдами и плеером другого через тот
же защищённый канал (`/melete/v1/rc/*`).

Отладка: каждый отказ (незнакомый ключ, не тот отпечаток) пишется в журнал на обеих сторонах — отчёт о проблеме с
двух устройств обычно сразу показывает причину.

## Гости в своей сети

`core/guest.js` + сервер `src-tauri/src/guest.rs` (порт 53320), страница гостя — `guest.html` + `src/guest/`
(без ядра). Гости в той же сети открывают адрес компьютера или QR-код и видят песни, тексты, аккорды, сет-лист,
слушают записи по одной — только чтение. Вход открытый или по QR с подтверждением; ведёт хозяин, ведение
передаётся. Проработка — `docs/guest-web.md`.

## Ансамбль

`core/ensemble.js`, экран — `screens/ensemble.js`. Каждый пишет свою партию своим телефоном, компьютер ведёт дубль
(сигнал и счёт), собирает записи и выравнивает их по звуковому сигналу (`audio/align.js`: смещение и ход часов —
кварцы телефонов расходятся до 30 мс за 5 минут). Итог — проект студии и по желанию чистые дорожки.

## LocalSend

Windows (`src-tauri/src/localsend.rs`, `core/localsend.js`): компьютер виден приложению LocalSend на телефоне как
«Melete · имя»; присланные файлы ложатся в папку Melete и через её синхронизацию — в медиатеку. Выключено по
умолчанию; нужна выбранная папка.

## Главный экран Ἐλάχιστον

Отдельное приложение в том же репозитории (`launcher/`, `src/launcher/`). С Melete связан только мостом на Android
(`core/bridge.js`, `BridgePlugin.java`): адресные рассылки без сети — идёт ли занятие, что звучит, неделя.
Договор — `docs/launcher-bridge.md`, само приложение — `docs/launcher.md`.
