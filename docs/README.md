# Документы проекта

С чего начать: `README.md` (что такое Melete) → `ARCHITECTURE.md` (замысел и устройство) → `docs/tech/` (главы).

## В корне репозитория

| Файл | Для кого и о чём |
|---|---|
| `README.md`, `README.en.md` | всем: что умеет приложение, где взять, как собрать |
| `ARCHITECTURE.md` | разработчику: замысел, правила, слои кода, путь от запуска до статистики |
| `MODULE_SPEC.md` | автору инструмента: контракт модуля и всё, что даёт `ctx` |
| `CLAUDE.md` | Claude Code: принципы, правила работы, короткая карта (читается в начале каждой сессии) |
| `DECISIONS.md` | всем: решения автора с датами — почему сделано так |
| `ROADMAP.md` | всем: этапы и статус |
| `LICENSE`, `LICENSES.md` | GPL‑3.0; сторонние компоненты и их лицензии |

## Техническая документация — `docs/tech/`

Данные, ядро и экраны, модули, звук, музыка и разбор записей, связь, платформы и сборка, надёжность, тесты,
соглашения по коду. Оглавление — `docs/tech/README.md`.
