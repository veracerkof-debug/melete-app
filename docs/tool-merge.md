# Объединение инструментов — план (21.11.2026)

Решение автора записано в `DECISIONS.md` («Объединение инструментов»): тренажёр (слух + ритм + вокал), студия + лупер, теория + учебник,
глайдер + терменвокс. Здесь — как это устроено сейчас и как делать. **Ничего из этого не реализовано.**

## Что уже есть в коде
- У модуля может быть `meta.group` (`session.js: groupOf, members`): модули одной группы — один значок нижней панели сессии и одно окно с переключателем
  между ними; имя группы — ключ `group.<id>` (в `ru.json` остались `group.train` «Слух и ритм», `group.rhythm`, `group.keys`). Сейчас ни у одного модуля `group` не задан.
- Вкладка «Инструменты», «Быстрый доступ», главная и статистика знают **отдельные модули** (`meta.id`): плитки, настройки видимости (`settings.tools…`),
  порядок, подсказки (`help`), данные модуля (`ctx.data()` — ключ по id). Раскладки окон (`wsMap`, `w.panes`), порядок панели (`dockOrder`, `song.dock`) хранят id.

## Два пути
- **А. Группа в ядре (рекомендуется).** Модули остаются отдельными (свои `ctx`, данные, тесты), ядро показывает группу как **одну плитку и один значок**; внутри окна —
  переключатель отделов (слух | ритм | вокал). Плюсы: данные и ключи не трогаются, модуль можно мерить отдельно, откат — убрать `group`. Минусы: нужно научить
  «Инструменты», быстрый доступ, главную и статистику показывать группы; миграция id в раскладках и порядке панели (старый id → id группы).
- **Б. Настоящее слияние кода** (один модуль с разделами). Чище внутри, но переписывать тесты, ключи данных, i18n, подсказки; риск потери данных при переносе;
  дорого. Только если А упрётся в ограничения.

## Порядок работ (по пути А)
1. Ядро: `meta.group` + плитка группы в «Инструментах», в быстром доступе и на главной; значок и имя (`group.<id>` ru/uz/en/el); тест `tests/groups.test.js`.
2. Миграция id (один раз при запуске): `dockOrder`, `song.dock`, `wsMap`/`w.panes`, быстрый доступ, настройки видимости: старый id → id группы; тест совместимости (`tests/compat.test.js`).
3. По одной группе, от простого к сложному: **глайдер + терменвокс** (две поверхности), **теория + учебник**, **студия + лупер** (+ режим «Лупер» одной кнопкой),
   **тренажёр** (слух + ритм + вокал, потом 10 уровней и «Начать занятие» — отдельной большой работой).
4. Витрина: посев демо-данных на новые id (`src/showcase/seeds`, правило 13); `docs/tech/modules.md`, `ARCHITECTURE.md`.
